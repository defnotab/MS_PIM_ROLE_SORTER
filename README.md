# PIM Role Auto Sorter

Automatically sorts Microsoft Entra PIM roles alphabetically by the **Role** column whenever you open the **My Roles** page.

## Features

- ✅ Automatically sorts roles alphabetically
- ✅ Works with Azure Portal, Microsoft Entra Admin Center, Microsoft Intune portal
- ✅ No configuration required
- ✅ No data collection or telemetry
- ✅ No external services or remote code

## Installation

### Microsoft Edge

1. Download the latest release ZIP.
2. Extract the ZIP file.
3. Open `edge://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted extension folder.

### Google Chrome

1. Download the latest release ZIP.
2. Extract the ZIP file.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted extension folder.

## Supported Pages

- Microsoft Azure Portal PIM - My Roles
- Microsoft Entra Admin Center PIM - My Roles
- Microsoft Intune Portal - My Roles

## Privacy

This extension:

- Does not collect or store data
- Does not send information to external services
- Does not use analytics or tracking
- Runs entirely in your browser
